# Kasuwa 🛍️

A responsive online store demo with a cream, navy and orange design.

## Features
- Category icons, a rotating swipeable banner and a smart search
- Product pages with swipeable photo galleries, specs, ratings and reviews
- Cart, wishlist, orders and a pending reviews list
- Login, sign up and an editable profile with a photo
- Light and dark mode, and a menu drawer
- Works on phones and computers

## Note
This is a front-end demo. Accounts, carts and reviews are saved only in
the visitor's own browser, and there is no payment or server.
Product photos are placeholders.
